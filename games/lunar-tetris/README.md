# 07. Тетрис: стройка на Луне — Удаление заполненных рядов

Тетрис принимает фигуры, но полные ряды остаются. Удалите их за один проход по полю, сохранив порядок остальных.

## Один блок реализации

Замените тело **[TetrisRules.removeFullRows](src/main/java/edu/course/games/lunartetris/domain/TetrisRules.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

На месте убрать полностью ненулевые строки; остальные опустить вниз, верх заполнить нулями. Вернуть число удалённых строк.

Непустая прямоугольная матрица ширины >0; строки — разные объекты. Требуемая сложность: O(h*w), O(1) доп. памяти.

Примеры: [[1,1],[0,2],[3,3]] → [[0,0],[0,0],[0,2]], результат 2.

## На что обратить внимание

Два соседних полных ряда, все полные, ни одного полного; ссылки на строки поля сохраняются.

## Как выполнить и проверить

1. Откройте метод и его вызов в `LunarTetrisGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :lunar-tetris -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 7
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
