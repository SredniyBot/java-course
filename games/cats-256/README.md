# 16. Котики 256 — Один сдвиг плиток

После команды влево плитки остаются на месте. Выполните сдвиг и слияния за один ход.

## Один блок реализации

Замените тело **[TileRules.mergeLeft](src/main/java/edu/course/games/cats256/domain/TileRules.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Вернуть новый ряд: убрать нули, слить соседние равные числа один раз слева направо, дополнить нулями. Оригинал не менять.

row не null; элементы 0 либо степени 2 ≤2^29; пустой ряд допустим. Требуемая сложность: O(n) времени/памяти.

Примеры: mergeLeft([2,2,2,2]) → [4,4,0,0]; mergeLeft([2,2,4,0]) → [4,4,0,0]; mergeLeft([2,0,2]) → [4,0,0].

## На что обратить внимание

[2,2,2,2] превращается в [4,4,0,0], а не в [8,0,0,0]. Исходный массив неизменен.

## Как выполнить и проверить

1. Откройте метод и его вызов в `Cats256Game`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :cats-256 -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 16
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.
