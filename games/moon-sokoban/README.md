# 17. Склад лунного сыра — Атомарный толчок ящика

Персонаж ходит, но ящики не двигаются. Попробуйте сдвинуть один ящик в указанном направлении.

## Один блок реализации

Замените тело **[WarehouseRules.tryPushBox](src/main/java/edu/course/games/moonsokoban/domain/WarehouseRules.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Клетка (r,c) содержит ящик 2. Если следующая по направлению клетка внутри поля и равна 0, перенести ящик туда и вернуть true; иначе оставить поле и вернуть false.

b непустой прямоугольный; (r,c) внутри и содержит 2; |dr|+|dc|=1; строки разные. Требуемая сложность: O(1).

Примеры: tryPushBox([[2,0]],0,0,0,1) → true, поле [[0,2]]; для [[2,1]] → false и поле неизменно.

## На что обратить внимание

Занятая клетка и край поля возвращают false и сохраняют всё поле. Это обычный исход хода.

## Как выполнить и проверить

1. Откройте метод и его вызов в `MoonSokobanGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :moon-sokoban -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 17
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.
