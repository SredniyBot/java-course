# 11. Спасите воздушный шар — Повторная буква не стоит жизни

Повторное нажатие снова уменьшает запас попыток. В слове несколько одинаковых букв.

## Что вы исследуете

Множество догадок отличается от последовательности нажатий; слово и маска — разные данные.

Темы: Set, инварианты, терминальные состояния. Для доказательства корректности используйте понятия лекции 3: контракт, класс входов, независимый oracle, граница и регрессия. Формальные доказательства не требуются; требуется объяснить основание каждого важного assertion.

## Перед началом

Предыдущая работа: [10. Словопад](../word-rain/README.md). Переносите её практику проверки, а не её код.

Работа 11/25. Ориентир 195–225 минут. Кроме базовых методов обязательна новая модель с тестами и подключением к UI. Не складывайте состояние в static.

## Обязательная работа: Сессия угадывания

1. Запустите демо и опишите наблюдаемый дефект: действие → результат → ожидаемое поведение. Баннер показывает вызванные незавершённые методы, а не процент готовности.
2. Реализуйте базовые методы по контрактам ниже. Заглушку ExercisePreview.unfinished заменяйте целиком; не включайте preview внутри acceptance-тестов.
3. Добавьте GuessSession для непустого слова A–Z и положительного лимита ошибок. guess(char) раскрывает все вхождения; новый промах расходует шанс, повтор не меняет состояние. Неверный символ — IllegalArgumentException без изменений. После победы/поражения команды не меняют состояние. Подключите UI.
4. Тестируйте повтор-повтор, промах-повтор, последнюю попытку. Возвращайте immutable результат; объясните Set против List.
5. Повторите исходный сценарий в окне. Отдельно проверьте F5, F6 и ошибочный ввод. Сохраните команду проверки и её результат.

## Приёмка

Базовые публичные тесты обязательны, но не исчерпывают работу. Новая часть оценивается по условиям пункта 3 и доказательствам пункта 4. Зелёные tests без обязательной новой функциональности не означают завершение. Нельзя ослаблять существующий контракт, подгонять expected или удалять проверки ради зелёного статуса.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в WordMask.

### `String revealGuessedLetters(String word,String guessed)`

- **WHAT / contract:** Для каждой буквы word добавить саму букву, если она встречается в guessed, иначе _. После каждой позиции добавить пробел.
- **Constraints:** word/guessed не null, состоят из BMP-букв без суррогатов. Регистр значим; пустые строки допустимы. Требуемая сложность: O(word.length*guessed.length).
- **Examples:** revealGuessedLetters("JAVA","A") → "_ A _ A "; revealGuessedLetters("","") → "".
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `revealGuessedLetters`, не совпадающий с examples.
- **Typical pitfalls:** После последнего символа тоже пробел; повторные буквы открываются вместе.

### `boolean isFullyGuessed(String word,String guessed)`

- **WHAT / contract:** Все буквы word встречаются в guessed. Повторы не требуют повторных догадок.
- **Constraints:** Те же ограничения на строки, что у revealGuessedLetters. Требуемая сложность: O(word.length*guessed.length).
- **Examples:** isFullyGuessed("JAVA","JAV") → true; isFullyGuessed("JAVA","JA") → false; isFullyGuessed("","") → true.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `isFullyGuessed`, не совпадающий с examples.
- **Typical pitfalls:** Количество догадок не равно количеству открытых букв; повторы игнорируются.

## Запуск и проверки

Из корня: ./mvnw -DskipTests package, затем java -jar app/target/java-games-app-1.0.0.jar 11.
На Windows используйте .\mvnw.cmd. Это компиляция и запуск демо, не приёмка.

Приёмка: ./mvnw -pl :balloon-rescue -am verify. Незавершённые методы дают IncompleteExerciseException.
При запуске окна та же заглушка даёт намеренно неполноценное поведение. Частично реализованная игра использует ваши готовые методы; ошибки вашего кода не заменяются демо.
F5 сбрасывает сцену; после изменения кода нужна пересборка. В каталоге src/test/java — настоящие Jupiter-тесты.
