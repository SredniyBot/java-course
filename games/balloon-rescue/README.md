# 11. Спасите воздушный шар — Маска загаданного слова

Игрок вводит буквы, но подсказка остаётся закрытой. Постройте маску целого слова.

## Один блок реализации

Замените тело **[WordMask.revealGuessedLetters](src/main/java/edu/course/games/balloonrescue/domain/WordMask.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Для каждой буквы word добавить саму букву, если она встречается в guessed, иначе _. После каждой позиции добавить пробел.

word/guessed не null, состоят из BMP-букв без суррогатов. Регистр значим; пустые строки допустимы. Требуемая сложность: O(word.length*guessed.length).

Примеры: revealGuessedLetters("JAVA","A") → "_ A _ A "; revealGuessedLetters("","") → "".

## На что обратить внимание

Повторяющиеся буквы открываются одновременно; после последнего символа тоже есть пробел.

## Как выполнить и проверить

1. Откройте метод и его вызов в `BalloonRescueGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :balloon-rescue -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 11
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

## Готово, когда

- Описанное действие работает в окне, а тесты выбранного модуля проходят без изменения ожидаемых результатов и без включения preview в тестах.
- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
- Вы можете ответить: **Какие данные меняет операция? Что вернётся для пустого слова?**

Сдайте реализацию и свои проверки в одном коммите. Краткое объяснение спорного решения достаточно оставить в описании коммита — отдельные DESIGN/REGRESSION/AI_USAGE-файлы не нужны. Если пользовались AI, укажите, что проверили самостоятельно; на защите потребуется объяснить код и изменить один сценарий.
