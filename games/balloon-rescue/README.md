# 11. Спасите воздушный шар

Откройте секретное слово до шести ошибок.

## Learning outcomes
Строковый вывод и повторяющиеся символы. Java: Строки, поиск символов, условия. После работы студент умеет объяснить контракт и подтвердить его тестом, а не только показать работающий экран.

## Prerequisites
Базовый синтаксис Java, методы и запуск Maven. Предыдущие игры/знания: 09,10. Уровень 2/3, ориентир 60–75 минут без установки JDK.

## Milestones
1. До реализации составьте таблицу граничных случаев и определите владельца массивов.
2. Реализуйте методы с соблюдением контрактов; самостоятельно выберите цикл и вспомогательные методы.
3. Добавьте тест отсутствия лишних изменений и один параметризованный тест.
4. Объясните сложность и продемонстрируйте игру.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в WordMask.

### `String revealGuessedLetters(String word,String guessed)`

- **WHAT / contract:** Для каждой буквы word добавить саму букву, если она встречается в guessed, иначе _. После каждой позиции добавить пробел.
- **Constraints:** word/guessed не null, состоят из BMP-букв без суррогатов. Регистр значим; пустые строки допустимы. Требуемая сложность: O(word.length*guessed.length).
- **Examples:** revealGuessedLetters("JAVA","A") → "_ A _ A "; revealGuessedLetters("","") → "".
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `revealGuessedLetters`, не совпадающий с examples.
- **Typical pitfalls:** После последнего символа тоже пробел; повторные буквы открываются вместе.

### `boolean isFullyGuessed(String word,String guessed)`

- **WHAT / contract:** Все буквы word встречаются в guessed. Повторы не требуют повторных догадок.
- **Constraints:** Те же ограничения на строки, что у revealGuessedLetters. Требуемая сложность: O(word.length*guessed.length).
- **Examples:** isFullyGuessed("JAVA","JAV") → true; isFullyGuessed("JAVA","JA") → false; isFullyGuessed("","") → true.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `isFullyGuessed`, не совпадающий с examples.
- **Typical pitfalls:** Количество догадок не равно количеству открытых букв; повторы игнорируются.

## Tests и запуск
Из корня репозитория: `./mvnw -pl :balloon-rescue -am test`. Windows: `.\mvnw.cmd -pl :balloon-rescue -am test`.
Проверки находятся в `src/test/java/edu/course/games/balloonrescue/domain`. Это Jupiter, не отдельный main.
После полной сборки `./mvnw verify` запустите `java -jar app/target/java-games-app-1.0.0.jar 11`.
В IDE запустите `edu.course.app.Launcher` с аргументом `11`. F5 сбрасывает игру, F6 ставит на паузу; код после правки нужно перекомпилировать.
В студенческой выдаче тесты изначально красные из-за незаполненных методов. Это ожидаемо; отключать их нельзя.

Можно использовать AI для объяснения API, поиска гипотез и критики тестов. В `AI_USAGE.md` укажите инструмент, задачу, что принято и как независимо проверено (или «не использовался»). Не засчитывается тест, чей expected просто скопирован из реализации.

1. Объясните `revealGuessedLetters` на входе, которого нет в примерах.
2. Какой объект изменяется, кто ещё может держать ссылку на него?
3. Какой тест упадёт при ошибке: После последнего символа тоже пробел; повторные буквы открываются вместе.
4. Выполните небольшой change request без повторной генерации всего класса.
