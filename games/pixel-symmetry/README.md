# 13. Мастерская симметрии — Зеркало для рисунка

Кисть уже работает. Реализуйте одно действие: отразить левую половину рисунка вправо.

## Один блок реализации

Замените тело **[SymmetryRules.mirrorLeftToRight](src/main/java/edu/course/games/pixelsymmetry/domain/SymmetryRules.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Скопировать левую половину в правую, отражая относительно вертикальной оси. Нечётную центральную колонку сохранить.

Строки не null и разные объекты; допустимы разная длина и пустые строки. Требуемая сложность: O(числа элементов), O(1) доп. памяти.

Примеры: mirrorLeftToRight([[1,2,3,4,5]]) → [[1,2,3,2,1]].

## На что обратить внимание

Нечётная ширина оставляет центральный столбец прежним. Повторное отражение ничего не меняет.

## Как выполнить и проверить

1. Откройте метод и его вызов в `PixelSymmetryGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :pixel-symmetry -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 13
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

## Готово, когда

- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
