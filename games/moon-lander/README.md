# 02. Лунная доставка — Управление тягой

Корабль зависает: новая скорость всегда равна нулю. Верните накопление скорости под действием гравитации и двигателя.

## Один блок реализации

Замените тело **[LanderPhysics.nextVerticalSpeed](src/main/java/edu/course/games/moonlander/domain/LanderPhysics.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Ускорение вниз 65, двигатель добавляет ускорение вверх 130. Вернуть новую скорость.

current конечна, abs ≤ 10^6; dt ∈ [0,1], секунды; положительная скорость направлена вниз. Требуемая сложность: O(1).

Примеры: nextVerticalSpeed(10,false,0.2) → 23; nextVerticalSpeed(10,true,0.2) → -3; dt=0 сохраняет current.

## На что обратить внимание

Рассмотрите нулевую длительность, включение двигателя при падении и движение вверх.

## Как выполнить и проверить

1. Откройте метод и его вызов в `MoonLanderGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :moon-lander -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 2
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

## Готово, когда

- Описанное действие работает в окне, а тесты выбранного модуля проходят без изменения ожидаемых результатов и без включения preview в тестах.
- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
- Вы можете ответить: **Почему включение двигателя не обязано сразу изменить знак скорости?**

Сдайте реализацию и свои проверки в одном коммите. Краткое объяснение спорного решения достаточно оставить в описании коммита — отдельные DESIGN/REGRESSION/AI_USAGE-файлы не нужны. Если пользовались AI, укажите, что проверили самостоятельно; на защите потребуется объяснить код и изменить один сценарий.
