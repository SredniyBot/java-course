# 22. Радио UTF-8 — Передача оборвалась между байтами

Незаконченный пакет нельзя сразу объявлять повреждённым или молча заменять символом замены.

## Что вы исследуете

Обрезанный допустимый префикс и некорректный UTF-8 имеют разные результаты.

Темы: CharsetDecoder, протокол, потоковое состояние. Для доказательства корректности используйте понятия лекции 3: контракт, класс входов, независимый oracle, граница и регрессия. Формальные доказательства не требуются; требуется объяснить основание каждого важного assertion.

## Приёмка

Базовые публичные тесты обязательны, но не исчерпывают работу. Новая часть оценивается по условиям пункта 3 и доказательствам пункта 4. ## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в Utf8Codec.

### `int toUnsigned(byte value)`

- **WHAT / contract:** Представить byte как целое 0…255.
- **Constraints:** Любое значение byte от -128 до 127. Требуемая сложность: O(1).
- **Examples:** toUnsigned((byte)-1) → 255; toUnsigned((byte)-128) → 128; toUnsigned((byte)0) → 0.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `toUnsigned`, не совпадающий с examples.
- **Typical pitfalls:** Обычный cast в int сохраняет знак.

### `String decodePrefix(byte[] packet,int count)`

- **WHAT / contract:** Строго декодировать первые count байтов UTF-8. При CharacterCodingException вернуть строку <ошибка>. Остаток массива не читать.
- **Constraints:** packet не null; 0≤count≤packet.length. При некорректном/обрезанном UTF-8 вернуть ровно <ошибка>. Требуемая сложность: O(count).
- **Examples:** decodePrefix([0x41,0xFF],1) → "A"; count=2 → "<ошибка>"; count=0 → ""; одиночный 0xD0 → "<ошибка>".
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `decodePrefix`, не совпадающий с examples.
- **Typical pitfalls:** new String заменяет ошибочные байты без отказа; хвост после count не декодировать.

## Запуск и проверки

Из корня: ./mvnw -DskipTests package, затем java -jar app/target/java-games-app-1.0.0.jar 22.
На Windows используйте .\mvnw.cmd. Это компиляция и запуск демо, не приёмка.

Приёмка: ./mvnw -pl :utf8-radio -am verify. Незавершённые методы дают IncompleteExerciseException.
При запуске окна та же заглушка даёт намеренно неполноценное поведение. Частично реализованная игра использует ваши готовые методы; ошибки вашего кода не заменяются демо.
F5 сбрасывает сцену; после изменения кода нужна пересборка. В каталоге src/test/java — настоящие Jupiter-тесты.
