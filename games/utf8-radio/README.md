# 22. Радио UTF-8 — Строгий приём радиограммы

Интерфейс уже умеет показывать ошибку связи. Реализуйте декодер, который различает корректный текст и повреждённый UTF-8.

## Один блок реализации

Замените тело **[Utf8Codec.decodeStrict](src/main/java/edu/course/games/utf8radio/domain/Utf8Codec.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Декодировать первые count байтов как полный текст UTF-8. Некорректные и оборванные последовательности отклоняются, без подстановки символа замены. Хвост массива не читается; массив не меняется.

0 ≤ count ≤ packet.length. Ошибочный UTF-8 является проверяемым отказом, а не допустимым результатом. Требуемая сложность: O(count).

Примеры: [0x41,0xFF], count=1 → "A"; count=2 → CharacterCodingException; count=0 → ""; [0xD0], count=1 → CharacterCodingException.

### Отказы

- `NullPointerException`: если packet равен null.
- `IndexOutOfBoundsException`: если count вне диапазона 0..packet.length.
- `CharacterCodingException`: если выбранный префикс не является полным корректным UTF-8.

Если нарушены несколько условий сразу, порядок их проверки не задан. Для проверки конкретного отказа нарушайте одно условие.

## На что обратить внимание

Поймайте именно CharacterCodingException в тесте; неверный count — отдельная ошибка вызова API.

## Как выполнить и проверить

1. Откройте метод и его вызов в `Utf8RadioGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :utf8-radio -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 22
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.
