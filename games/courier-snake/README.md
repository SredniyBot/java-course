# 06. Змейка-курьер

Съешьте 10 посылок, не столкнувшись с собой.

## Learning outcomes
Параллельные массивы и безопасная мутация. Java: Одномерные массивы, сдвиг, границы. После работы студент умеет объяснить контракт и подтвердить его тестом, а не только показать работающий экран.

## Prerequisites
Базовый синтаксис Java, методы и запуск Maven. Предыдущие игры/знания: 05. Уровень 1/3, ориентир 75–100 минут без установки JDK.

## Milestones
1. Нарисуйте два граничных примера на бумаге.
2. Реализуйте первый метод по описанию; прогоните тесты.
3. Реализуйте остальные методы, добавьте тест на границу.
4. Проверьте обычный ход и перезапуск окна.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в SnakeRules.

### `void advanceBody(int[] xs,int[] ys,int length,int nx,int ny)`

- **WHAT / contract:** Сдвинуть первые length элементов вправо и записать новую голову в [0]. Сдвиг справа налево; length>=1.
- **Constraints:** xs, ys не null и не один объект; 1 ≤ length ≤ min(xs.length,ys.length); любые int координаты. Требуемая сложность: O(length), O(1) доп. памяти.
- **Examples:** xs=[3,2,1,99], ys=[4,4,4,88], length=3, новая голова=(4,4) → xs=[4,3,2,99], ys без изменений.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `advanceBody`, не совпадающий с examples.
- **Typical pitfalls:** Сдвиг слева направо затирает тело. Хвост массивов с index≥length не менять.

### `boolean occupiesCell(int[] xs,int[] ys,int length,int x,int y)`

- **WHAT / contract:** Есть ли координата (x,y) среди первых length элементов. length может быть 0.
- **Constraints:** xs, ys не null; 0 ≤ length ≤ min длин. Требуемая сложность: O(length).
- **Examples:** occupiesCell([2,8],[3,9],1,8,9) → false; length=2 → true; length=0 → false.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `occupiesCell`, не совпадающий с examples.
- **Typical pitfalls:** Обе координаты должны совпасть в одной позиции, не в разных сегментах.

## Tests и запуск
Из корня репозитория: `./mvnw -pl :courier-snake -am test`. Windows: `.\mvnw.cmd -pl :courier-snake -am test`.
Проверки находятся в `src/test/java/edu/course/games/couriersnake/domain`. Это Jupiter, не отдельный main.
После полной сборки `./mvnw verify` запустите `java -jar app/target/java-games-app-1.0.0.jar 6`.
В IDE запустите `edu.course.app.Launcher` с аргументом `6`. F5 сбрасывает игру, F6 ставит на паузу; код после правки нужно перекомпилировать.
В студенческой выдаче тесты изначально красные из-за незаполненных методов. Это ожидаемо; отключать их нельзя.

3. Какой тест упадёт при ошибке: Сдвиг слева направо затирает тело. Хвост массивов с index≥length не менять.
4. Выполните небольшой change request без повторной генерации всего класса.
