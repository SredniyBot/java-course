## Поведение

Сдвинуть первые length элементов вправо и записать новую голову в [0]. length должен быть положительным. Перед изменением проверьте оба массива и активную длину. При отказе ни один элемент не меняется. Элементы с индексами от length и выше сохраняются.

xs и ys — разные ненулевые массивы; 1 ≤ length ≤ min(xs.length,ys.length). Требуемая сложность: O(length), O(1) доп. памяти.

Примеры: xs=[3,2,1,99], ys=[4,4,4,88], length=3, новая голова=(4,4) → xs=[4,3,2,99], ys без изменений.

### Отказы

- `NullPointerException`: если xs или ys равен null.
- `IllegalArgumentException`: если массивы совпадают по ссылке или length вне диапазона 1..min(xs.length, ys.length).

Если нарушены несколько условий сразу, порядок их проверки не задан. Для проверки конкретного отказа нарушайте одно условие.

## На что обратить внимание

Ошибочная длина или общий массив координат должны отклоняться до первой записи.

## Как выполнить и проверить

1. Откройте метод и его вызов в `CourierSnakeGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :courier-snake -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 6
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.
