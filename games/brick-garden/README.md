# 05. Кирпичный сад — Кирпич или щель

Мяч не разрушает стену. Определите, какому кирпичу принадлежит координата удара.

## Один блок реализации

Замените тело **[BrickRules.columnAt](src/main/java/edu/course/games/brickgarden/domain/BrickRules.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Кирпичи начинаются с x=80, шаг 100, ширина 94, всего 8. Вернуть индекс или -1, включая промежутки.

x конечен, abs ≤ 10^6. Кирпич c занимает [80+100*c,174+100*c), c=0..7. Требуемая сложность: O(1).

Примеры: columnAt(80) → 0; columnAt(173.9) → 0; columnAt(174) → -1; columnAt(180) → 1; columnAt(874) → -1.

## На что обратить внимание

Проверьте начало и конец поверхности, щель и отрицательную координату.

## Как выполнить и проверить

1. Откройте метод и его вызов в `BrickGardenGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :brick-garden -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 5
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

## Готово, когда

- Описанное действие работает в окне, а тесты выбранного модуля проходят без изменения ожидаемых результатов и без включения preview в тестах.
- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.

Если пользовались AI, укажите, что проверили самостоятельно; на защите потребуется объяснить код и изменить один сценарий.
