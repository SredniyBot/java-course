# 08. Сапёр на Марсе

Откройте все безопасные клетки. Первый ход безопасен.

## Learning outcomes
Окрестность и квантор «для всех». Java: Вложенные циклы, соседи, boolean[][]. После работы студент умеет объяснить контракт и подтвердить его тестом, а не только показать работающий экран.

## Prerequisites
Базовый синтаксис Java, методы и запуск Maven. Предыдущие игры/знания: 05. Уровень 2/3, ориентир 75–100 минут без установки JDK.

## Milestones
1. До реализации составьте таблицу граничных случаев и определите владельца массивов.
2. Реализуйте методы с соблюдением контрактов; самостоятельно выберите цикл и вспомогательные методы.
3. Добавьте тест отсутствия лишних изменений и один параметризованный тест.
4. Объясните сложность и продемонстрируйте игру.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в MinefieldRules.

### `int countAdjacentMines(boolean[][] mines,int row,int col)`

- **WHAT / contract:** Посчитать мины в восьми соседних клетках. Саму клетку не считать; не выходить за границы.
- **Constraints:** Непустая прямоугольная матрица; row,col внутри. Требуемая сложность: O(1).
- **Examples:** countAdjacentMines([[true]],0,0) → 0; в полностью заминированном поле 3×3 центр → 8, угол → 3.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `countAdjacentMines`, не совпадающий с examples.
- **Typical pitfalls:** Центральная клетка не сосед; диагонали входят в восемь направлений.

### `boolean allSafeCellsOpen(boolean[][] mines,boolean[][] open)`

- **WHAT / contract:** Все клетки без мин открыты. Флаги не влияют на победу.
- **Constraints:** Прямоугольные mines/open одинакового размера, строки не null; пустые поля допустимы. Требуемая сложность: O(h*w).
- **Examples:** mines=[[true,false]], open=[[false,true]] → true; open=[[true,false]] → false.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `allSafeCellsOpen`, не совпадающий с examples.
- **Typical pitfalls:** Мины открывать для победы не нужно; на поле только с минами условие выполнено.

## Tests и запуск
Из корня репозитория: `./mvnw -pl :mars-mines -am test`. Windows: `.\mvnw.cmd -pl :mars-mines -am test`.
Проверки находятся в `src/test/java/edu/course/games/marsmines/domain`. Это Jupiter, не отдельный main.
После полной сборки `./mvnw verify` запустите `java -jar app/target/java-games-app-1.0.0.jar 8`.
В IDE запустите `edu.course.app.Launcher` с аргументом `8`. F5 сбрасывает игру, F6 ставит на паузу; код после правки нужно перекомпилировать.
В студенческой выдаче тесты изначально красные из-за незаполненных методов. Это ожидаемо; отключать их нельзя.

## Optional extension / запрос на защите
Добавить раскрытие пустой области без рекурсивного переполнения стека.
Сохраните существующие контракты через адаптер либо документируйте согласованное изменение и обновите UI с тестами. Полная эталонная версия закрывает базовые контракты; этот запрос студент выполняет самостоятельно.

Можно использовать AI для объяснения API, поиска гипотез и критики тестов. В `AI_USAGE.md` укажите инструмент, задачу, что принято и как независимо проверено (или «не использовался»). Не засчитывается тест, чей expected просто скопирован из реализации.

1. Объясните `countAdjacentMines` на входе, которого нет в примерах.
2. Какой объект изменяется, кто ещё может держать ссылку на него?
3. Какой тест упадёт при ошибке: Центральная клетка не сосед; диагонали входят в восемь направлений.
4. Выполните небольшой change request без повторной генерации всего класса.
