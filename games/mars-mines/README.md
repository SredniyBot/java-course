# 08. Сапёр на Марсе — Числа на минном поле

Открытые клетки не показывают опасность. Посчитайте мины вокруг выбранной клетки.

## Один блок реализации

Замените тело **[MinefieldRules.countAdjacentMines](src/main/java/edu/course/games/marsmines/domain/MinefieldRules.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Посчитать мины в восьми соседних клетках. Саму клетку не считать; не выходить за границы.

Непустая прямоугольная матрица; row,col внутри. Требуемая сложность: O(1).

Примеры: countAdjacentMines([[true]],0,0) → 0; в полностью заминированном поле 3×3 центр → 8, угол → 3.

## На что обратить внимание

Сравните угол, край, центр и поле 1×1. Мина в самой клетке не учитывается.

## Как выполнить и проверить

1. Откройте метод и его вызов в `MarsMinesGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :mars-mines -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 8
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

- Описанное действие работает в окне, а тесты выбранного модуля проходят без изменения ожидаемых результатов и без включения preview в тестах.
- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
