# 08. Сапёр на Марсе — Карта, которая не подсказывает

Сканер должен считать соседей в центре, углу и на узкой полосе. Флаг на мине ещё не означает победу.

## Что вы исследуете

Победа зависит от открытых безопасных клеток; собственная клетка не является соседом.

Темы: Конечные пространства, квантор все, пустое множество. Для доказательства корректности используйте понятия лекции 3: контракт, класс входов, независимый oracle, граница и регрессия. Формальные доказательства не требуются; требуется объяснить основание каждого важного assertion.

## Перед началом

Предыдущая работа: [07. Тетрис: стройка на Луне](../lunar-tetris/README.md). Переносите её практику проверки, а не её код.

Работа 8/25. Ориентир 150–180 минут. Алгоритм и тестовый оракул выберите самостоятельно; объясните, почему они не повторяют друг друга.

## Обязательная работа: Исчерпывающая малая планета

1. Запустите демо и опишите наблюдаемый дефект: действие → результат → ожидаемое поведение. Баннер показывает вызванные незавершённые методы, а не процент готовности.
2. Реализуйте базовые методы по контрактам ниже. Заглушку ExercisePreview.unfinished заменяйте целиком; не включайте preview внутри acceptance-тестов.
3. Переберите 512 конфигураций 3×3. Проверьте соседей центра оракулом по восьми явно заданным координатам. Добавьте 1×1, 1×N и закрытую единственную безопасную клетку.
4. Перебор конечен и детерминирован. Expected не вычисляется вызовом countAdjacentMines другой клетки.
5. Повторите исходный сценарий в окне. Отдельно проверьте F5, F6 и ошибочный ввод. Сохраните команду проверки и её результат.

## Приёмка

Базовые публичные тесты обязательны, но не исчерпывают работу. Новая часть оценивается по условиям пункта 3 и доказательствам пункта 4. Зелёные tests без обязательной новой функциональности не означают завершение. Нельзя ослаблять существующий контракт, подгонять expected или удалять проверки ради зелёного статуса.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в MinefieldRules.

### `int countAdjacentMines(boolean[][] mines,int row,int col)`

- **WHAT / contract:** Посчитать мины в восьми соседних клетках. Саму клетку не считать; не выходить за границы.
- **Constraints:** Непустая прямоугольная матрица; row,col внутри. Требуемая сложность: O(1).
- **Examples:** countAdjacentMines([[true]],0,0) → 0; в полностью заминированном поле 3×3 центр → 8, угол → 3.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `countAdjacentMines`, не совпадающий с examples.
- **Typical pitfalls:** Центральная клетка не сосед; диагонали входят в восемь направлений.

### `boolean allSafeCellsOpen(boolean[][] mines,boolean[][] open)`

- **WHAT / contract:** Все клетки без мин открыты. Флаги не влияют на победу.
- **Constraints:** Прямоугольные mines/open одинакового размера, строки не null; пустые поля допустимы. Требуемая сложность: O(h*w).
- **Examples:** mines=[[true,false]], open=[[false,true]] → true; open=[[true,false]] → false.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `allSafeCellsOpen`, не совпадающий с examples.
- **Typical pitfalls:** Мины открывать для победы не нужно; на поле только с минами условие выполнено.

## Запуск и проверки

Из корня: ./mvnw -DskipTests package, затем java -jar app/target/java-games-app-1.0.0.jar 8.
На Windows используйте .\mvnw.cmd. Это компиляция и запуск демо, не приёмка.

Приёмка: ./mvnw -pl :mars-mines -am verify. Незавершённые методы дают IncompleteExerciseException.
При запуске окна та же заглушка даёт намеренно неполноценное поведение. Частично реализованная игра использует ваши готовые методы; ошибки вашего кода не заменяются демо.
F5 сбрасывает сцену; после изменения кода нужна пересборка. В каталоге src/test/java — настоящие Jupiter-тесты.
