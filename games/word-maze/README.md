# 12. Буквенный лабиринт — Чтение выбранного пути

Клетки выбираются, но слово не собирается. Прочитайте активную часть пути и сообщите о неверном индексе.

## Один блок реализации

Замените тело **[WordPathRules.readPath](src/main/java/edu/course/games/wordmaze/domain/WordPathRules.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Собрать буквы первых length индексов path в строку. Ширина board[0].length. Читайте только первые length индексов; хвост может содержать любые значения. Повторы и несоседние клетки разрешены: проверку маршрута выполняет UI. Входы не меняются.

Непустое прямоугольное поле; 0 ≤ length ≤ path.length; активные индексы внутри поля. Требуемая сложность: O(length).

Примеры: readPath([[J,A],[V,A]],[0,1,2,3],4) → "JAVA"; length=0 → "".

### Отказы

- `NullPointerException`: если board или path равен null.
- `IllegalArgumentException`: если поле пустое, содержит null-строки, непрямоугольно либо length вне 0..path.length.
- `IndexOutOfBoundsException`: если активный индекс пути не принадлежит полю.

Если нарушены несколько условий сразу, порядок их проверки не задан. Для проверки конкретного отказа нарушайте одно условие.

## На что обратить внимание

Испорченный активный индекс — ошибка; такое же значение в неактивном хвосте игнорируется.

## Как выполнить и проверить

1. Откройте метод и его вызов в `WordMazeGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :word-maze -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 12
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
