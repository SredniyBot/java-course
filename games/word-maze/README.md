# 12. Буквенный лабиринт

Пройдите по буквам слова JAVA, выбирая соседние клетки.

## Learning outcomes
Преобразование плоских индексов в координаты. Java: StringBuilder, индексы, соседство. После работы студент умеет объяснить контракт и подтвердить его тестом, а не только показать работающий экран.

## Prerequisites
Базовый синтаксис Java, методы и запуск Maven. Предыдущие игры/знания: 05,11. Уровень 2/3, ориентир 60–90 минут без установки JDK.

## Milestones
1. До реализации составьте таблицу граничных случаев и определите владельца массивов.
2. Реализуйте методы с соблюдением контрактов; самостоятельно выберите цикл и вспомогательные методы.
3. Добавьте тест отсутствия лишних изменений и один параметризованный тест.
4. Объясните сложность и продемонстрируйте игру.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в WordPathRules.

### `boolean areSideNeighbors(int a,int b,int width)`

- **WHAT / contract:** Индексы одной сетки. Разрешено соседство только по стороне, без переноса между строками.
- **Constraints:** width>0, a,b ≥0, до 10^6; индексы одной сетки в построчной нумерации. Требуемая сложность: O(1).
- **Examples:** areSideNeighbors(2,3,3) → false; areSideNeighbors(1,4,3) → true; areSideNeighbors(1,1,3) → false.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `areSideNeighbors`, не совпадающий с examples.
- **Typical pitfalls:** Разность индексов 1 может пересекать границу строки; диагональ не сосед.

### `String readPath(char[][] board,int[] path,int length)`

- **WHAT / contract:** Собрать буквы первых length индексов path в строку. Ширина board[0].length.
- **Constraints:** board непустой прямоугольный, width>0; path не null; 0≤length≤path.length; первые length индексов внутри board. Требуемая сложность: O(length).
- **Examples:** readPath([[J,A],[V,A]],[0,1,2,3],4) → "JAVA"; length=0 → "".
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `readPath`, не совпадающий с examples.
- **Typical pitfalls:** Используется ширина, а не высота; элементы path после length не читать.

## Tests и запуск
Из корня репозитория: `./mvnw -pl :word-maze -am test`. Windows: `.\mvnw.cmd -pl :word-maze -am test`.
Проверки находятся в `src/test/java/edu/course/games/wordmaze/domain`. Это Jupiter, не отдельный main.
После полной сборки `./mvnw verify` запустите `java -jar app/target/java-games-app-1.0.0.jar 12`.
В IDE запустите `edu.course.app.Launcher` с аргументом `12`. F5 сбрасывает игру, F6 ставит на паузу; код после правки нужно перекомпилировать.
В студенческой выдаче тесты изначально красные из-за незаполненных методов. Это ожидаемо; отключать их нельзя.
