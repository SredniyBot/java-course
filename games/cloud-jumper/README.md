# 03. Облачный прыгун

Поднимитесь на 1200 метров по платформам.

## Learning outcomes
Пересечение за временной шаг. Java: Массивы, интервалы, состояние. После работы студент умеет объяснить контракт и подтвердить его тестом, а не только показать работающий экран.

## Prerequisites
Базовый синтаксис Java, методы и запуск Maven. Предыдущие игры/знания: 01,02. Уровень 1/3, ориентир 75–100 минут без установки JDK.

## Milestones
1. Нарисуйте два граничных примера на бумаге.
2. Реализуйте первый метод по описанию; прогоните тесты.
3. Реализуйте остальные методы, добавьте тест на границу.
4. Проверьте обычный ход и перезапуск окна.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в PlatformRules.

### `boolean crossesPlatform(double oldBottom,double newBottom,double vy,double x,int platformX,double platformY)`

- **WHAT / contract:** Посадка при движении вниз (vy>0), пересечении высоты платформы снизу экрана: oldBottom<=platformY<=newBottom; центр x в [platformX,platformX+140].
- **Constraints:** Конечные координаты/скорости abs ≤ 10^6; oldBottom и newBottom — низ персонажа, y растёт вниз. Требуемая сложность: O(1).
- **Examples:** crossesPlatform(90,110,20,150,100,100) → true; при vy=0 или -20 → false; x=240 допустим, x=241 нет.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `crossesPlatform`, не совпадающий с examples.
- **Typical pitfalls:** Недостаточно проверить новую высоту: персонаж мог быть ниже платформы до шага.

### `double wrapHorizontal(double x,double width)`

- **WHAT / contract:** Если x<0, прибавить width; если x>=width, вычесть width. За шаг выход не больше width.
- **Constraints:** width ∈ (0,10^6]; x ∈ [-width,2*width). Разрешён выход не более одной ширины. Требуемая сложность: O(1).
- **Examples:** wrapHorizontal(-1,960) → 959; wrapHorizontal(960,960) → 0; wrapHorizontal(0,960) → 0; wrapHorizontal(-960,960) → 0.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `wrapHorizontal`, не совпадающий с examples.
- **Typical pitfalls:** Правая граница исключена; % для отрицательных double не даёт требуемый перенос.

## Tests и запуск
Из корня репозитория: `./mvnw -pl :cloud-jumper -am test`. Windows: `.\mvnw.cmd -pl :cloud-jumper -am test`.
Проверки находятся в `src/test/java/edu/course/games/cloudjumper/domain`. Это Jupiter, не отдельный main.
После полной сборки `./mvnw verify` запустите `java -jar app/target/java-games-app-1.0.0.jar 3`.
В IDE запустите `edu.course.app.Launcher` с аргументом `3`. F5 сбрасывает игру, F6 ставит на паузу; код после правки нужно перекомпилировать.
В студенческой выдаче тесты изначально красные из-за незаполненных методов. Это ожидаемо; отключать их нельзя.

## Optional extension / запрос на защите
Разрешить ширину платформы как параметр и показать тест на сквозное падение.
Сохраните существующие контракты через адаптер либо документируйте согласованное изменение и обновите UI с тестами. Полная эталонная версия закрывает базовые контракты; этот запрос студент выполняет самостоятельно.
