# 01. Звёздный курьер — Груз у кромки экрана

Курьер должен подбирать груз ровно на границе радиуса. Ошибка в один пиксель меняет результат доставки.

## Что вы исследуете

Замкнутый интервал и круг попадания: диагональный сосед квадрата ещё не обязан лежать в круге.

Темы: Числа, boolean, замкнутый интервал. Для доказательства корректности используйте понятия лекции 3: контракт, класс входов, независимый oracle, граница и регрессия. Формальные доказательства не требуются; требуется объяснить основание каждого важного assertion.

## Перед началом

Методы Java, базовый синтаксис, опыт программирования.

Работа 1/25. Ориентир 45–75 минут. Сигнатуры и примеры заданы. Самостоятельно выберите контрпримеры.

## Обязательная работа: Таблица пяти полётов

1. Запустите демо и опишите наблюдаемый дефект: действие → результат → ожидаемое поведение. Баннер показывает вызванные незавершённые методы, а не процент готовности.
2. Реализуйте базовые методы по контрактам ниже. Заглушку ExercisePreview.unfinished заменяйте целиком; не включайте preview внутри acceptance-тестов.
3. До кода запишите пять входов и ответов: внутри, вне, на границе, вырожденный интервал и совпавшие центры. Затем добавьте параметризованный тест clampCoordinate и отдельный пример касания окружности.
4. Один пример должен опровергать проверку попадания по квадрату. Expected вычислите на рисунке, а не вызовом другого метода.
5. Повторите исходный сценарий в окне. Отдельно проверьте F5, F6 и ошибочный ввод. Сохраните команду проверки и её результат.

## Приёмка

Базовые публичные тесты обязательны, но не исчерпывают работу. Новая часть оценивается по условиям пункта 3 и доказательствам пункта 4. Зелёные tests без обязательной новой функциональности не означают завершение. Нельзя ослаблять существующий контракт, подгонять expected или удалять проверки ради зелёного статуса.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в CourierRules.

### `double clampCoordinate(double value, double min, double max)`

- **WHAT / contract:** Вернуть value в замкнутом диапазоне [min,max]. min <= max.
- **Constraints:** Все числа конечны, abs ≤ 10^6; min ≤ max. Требуемая сложность: O(1).
- **Examples:** clampCoordinate(-2,0,9) → 0; clampCoordinate(4,0,9) → 4; clampCoordinate(15,0,9) → 9; clampCoordinate(2,3,3) → 3.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `clampCoordinate`, не совпадающий с examples.
- **Typical pitfalls:** Нельзя возвращать min для любого значения; равные границы допустимы.

### `boolean isWithinRadius(double x, double y, double tx, double ty, double radius)`

- **WHAT / contract:** Центры касаются, если квадрат расстояния <= radius². Считать касание границы попаданием.
- **Constraints:** Конечные координаты с abs ≤ 10^6; radius от 0 до 10^6. Требуемая сложность: O(1).
- **Examples:** isWithinRadius(0,0,3,4,5) → true; radius=4 → false; совпавшие центры и radius=0 → true.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `isWithinRadius`, не совпадающий с examples.
- **Typical pitfalls:** Граница включена: <=, не <; сравнивайте величины в одинаковых единицах.

## Запуск и проверки

Из корня: ./mvnw -DskipTests package, затем java -jar app/target/java-games-app-1.0.0.jar 1.
На Windows используйте .\mvnw.cmd. Это компиляция и запуск демо, не приёмка.

Приёмка: ./mvnw -pl :star-courier -am verify. Незавершённые методы дают IncompleteExerciseException.
При запуске окна та же заглушка даёт намеренно неполноценное поведение. Частично реализованная игра использует ваши готовые методы; ошибки вашего кода не заменяются демо.
F5 сбрасывает сцену; после изменения кода нужна пересборка. В каталоге src/test/java — настоящие Jupiter-тесты.
