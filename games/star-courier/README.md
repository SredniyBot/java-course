# 01. Звёздный курьер

Соберите 10 звёзд, не вылетая за границы.

## Learning outcomes
Замкнутые интервалы и геометрический предикат. Java: Арифметика, сравнения, Math. После работы студент умеет объяснить контракт и подтвердить его тестом, а не только показать работающий экран.

## Prerequisites
Базовый синтаксис Java, методы и запуск Maven. Предыдущие игры/знания: —. Уровень 1/3, ориентир 45–60 минут без установки JDK.

## Milestones
1. Нарисуйте два граничных примера на бумаге.
2. Реализуйте первый метод по описанию; прогоните тесты.
3. Реализуйте остальные методы, добавьте тест на границу.
4. Проверьте обычный ход и перезапуск окна.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в CourierRules.

### `double clampCoordinate(double value, double min, double max)`

- **WHAT / contract:** Вернуть value в замкнутом диапазоне [min,max]. min <= max.
- **Constraints:** Все числа конечны, abs ≤ 10^6; min ≤ max. Требуемая сложность: O(1).
- **Examples:** clampCoordinate(-2,0,9) → 0; clampCoordinate(4,0,9) → 4; clampCoordinate(15,0,9) → 9; clampCoordinate(2,3,3) → 3.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `clampCoordinate`, не совпадающий с examples.
- **Typical pitfalls:** Нельзя возвращать min для любого значения; равные границы допустимы.

### `boolean isWithinRadius(double x, double y, double tx, double ty, double radius)`

- **WHAT / contract:** Центры касаются, если квадрат расстояния <= radius². Считать касание границы попаданием.
- **Constraints:** Конечные координаты с abs ≤ 10^6; radius от 0 до 10^6. Требуемая сложность: O(1).
- **Examples:** isWithinRadius(0,0,3,4,5) → true; radius=4 → false; совпавшие центры и radius=0 → true.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `isWithinRadius`, не совпадающий с examples.
- **Typical pitfalls:** Граница включена: <=, не <; сравнивайте величины в одинаковых единицах.

## Tests и запуск
Из корня репозитория: `./mvnw -pl :star-courier -am test`. Windows: `.\mvnw.cmd -pl :star-courier -am test`.
Проверки находятся в `src/test/java/edu/course/games/starcourier/domain`. Это Jupiter, не отдельный main.
После полной сборки `./mvnw verify` запустите `java -jar app/target/java-games-app-1.0.0.jar 1`.
В IDE запустите `edu.course.app.Launcher` с аргументом `1`. F5 сбрасывает игру, F6 ставит на паузу; код после правки нужно перекомпилировать.
В студенческой выдаче тесты изначально красные из-за незаполненных методов. Это ожидаемо; отключать их нельзя.

## Optional extension / запрос на защите
Добавить круг с внутренней запрещённой областью, сохранив прежний isWithinRadius.
Сохраните существующие контракты через адаптер либо документируйте согласованное изменение и обновите UI с тестами. Полная эталонная версия закрывает базовые контракты; этот запрос студент выполняет самостоятельно.

1. Объясните `clampCoordinate` на входе, которого нет в примерах.
2. Какой объект изменяется, кто ещё может держать ссылку на него?
3. Какой тест упадёт при ошибке: Нельзя возвращать min для любого значения; равные границы допустимы.
4. Выполните небольшой change request без повторной генерации всего класса.
