# 01. Звёздный курьер — Подбор груза

Курьер движется, но груз не подбирается. Восстановите проверку попадания в круг.

## Один блок реализации

Замените тело **[CourierRules.isWithinRadius](src/main/java/edu/course/games/starcourier/domain/CourierRules.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Груз подобран, если евклидово расстояние между центрами не превышает radius. Касание границы считается попаданием.

Конечные координаты с abs ≤ 10^6; radius от 0 до 10^6. Требуемая сложность: O(1).

Примеры: isWithinRadius(0,0,3,4,5) → true; radius=4 → false; совпавшие центры и radius=0 → true.

## На что обратить внимание

Сравните точку (3,4) на окружности радиуса 5 и точку (4,4) за её пределами.

## Как выполнить и проверить

1. Откройте метод и его вызов в `StarCourierGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :star-courier -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 1
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

## Готово, когда

- Описанное действие работает в окне, а тесты выбранного модуля проходят без изменения ожидаемых результатов и без включения preview в тестах.
- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
