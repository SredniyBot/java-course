# 18. Лазерная почта — Маршрут лазерного письма

Зеркала поворачиваются, но луч не идёт. Рассчитайте полный маршрут и причину остановки.

## Один блок реализации

Замените тело **[BeamRules.trace](src/main/java/edu/course/games/lasermail/domain/BeamRules.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Провести луч до приёмника, выхода из поля или повторного состояния (строка, столбец, входящее направление). Начальная клетка и приёмник включаются в маршрут; повторное состояние не добавляется. Приёмник проверяется до отражения. Направления: 0 вправо, 1 вниз, 2 влево, 3 вверх. Поле не меняется.

Непустое прямоугольное поле: 0 — пусто, / и \ — зеркала. Начало и приёмник внутри поля; направление 0..3. Требуемая сложность: O(число клеток).

Примеры: Поле [[0,0,0]], начало (0,0), направление 0, цель (0,2): маршрут [(0,0),(0,1),(0,2)], DELIVERED.

### Отказы

- `NullPointerException`: если mirrors равен null.
- `IllegalArgumentException`: если нарушена форма поля, алфавит клеток, координаты начала/цели или направление.

Если нарушены несколько условий сразу, порядок их проверки не задан. Для проверки конкретного отказа нарушайте одно условие.

## На что обратить внимание

Остановка в приёмнике, выход с поля и петля различаются; посещение клетки с другой стороны не означает петлю.

## Как выполнить и проверить

1. Откройте метод и его вызов в `LaserMailGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :laser-mail -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 18
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
