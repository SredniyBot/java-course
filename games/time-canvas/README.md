# 19. Холст времени

Воспроизведите образец. Кнопка Z отменяет ход, Y возвращает отменённый.

## Learning outcomes
Владение данными и глубокие снимки. Java: Глубокое копирование, aliasing, undo; null и значения по умолчанию. После работы студент умеет объяснить контракт и подтвердить его тестом, а не только показать работающий экран.

## Prerequisites
Базовый синтаксис Java, методы и запуск Maven. Предыдущие игры/знания: 13,17. Уровень 3/3, ориентир 100–150 минут без установки JDK.

## Milestones
1. Напишите короткую design note: типы данных, границы ответственности, альтернативы.
2. Зафиксируйте CanvasRules как адаптер для готового UI; внутренние классы, value objects и API проектируйте сами.
3. Реализуйте контракт и защитите выбор мутабельности; добавьте свои независимые тесты.
4. Обязательная защита: реализуйте запрос на изменение ниже и объясните, какие тесты защищают старое поведение.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в CanvasRules.

### `int[][] copyPixels(int[][] a)`

- **WHAT / contract:** Вернуть независимую копию прямоугольной матрицы int, включая копии всех строк.
- **Constraints:** a и строки не null; пустые и неодинаковые по длине строки допустимы. Требуемая сложность: O(числа элементов) времени/памяти.
- **Examples:** copyPixels([[1],[2,3]]) → равные значения; изменение copyPixels[0][0] не меняет a[0][0].
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `copyPixels`, не совпадающий с examples.
- **Typical pitfalls:** Копирование внешнего массива не копирует строки; даже строки длины 0 должны быть отдельными.

### `int countDifferences(int[][] a,int[][] b)`

- **WHAT / contract:** Посчитать позиции с разными значениями. Размеры совпадают.
- **Constraints:** a,b и строки не null; одинаковое число строк и попарные длины строк. Требуемая сложность: O(числа элементов).
- **Examples:** countDifferences([[1,2]],[[1,3]]) → 1; равные матрицы → 0.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `countDifferences`, не совпадающий с examples.
- **Typical pitfalls:** Сравнивать значения клеток, не ссылки; обе матрицы сохранить.

### `boolean hasPreviousSnapshot(int index,int[][][] snapshots)`

- **WHAT / contract:** Вернуть true, если index>0 и предыдущий снимок не null. В новом массиве ссылок неиспользованные элементы равны null. Индекс внутри snapshots.
- **Constraints:** snapshots не null; 0≤index<snapshots.length; элементы snapshots могут быть null. Требуемая сложность: O(1).
- **Examples:** hasPreviousSnapshot(0,[null]) → false; hasPreviousSnapshot(1,[[[1]],null]) → true; hasPreviousSnapshot(1,[null,null]) → false.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `hasPreviousSnapshot`, не совпадающий с examples.
- **Typical pitfalls:** Не читать index-1 до проверки index>0; текущее значение snapshots[index] не определяет возможность undo.

## Tests и запуск
Из корня репозитория: `./mvnw -pl :time-canvas -am test`. Windows: `.\mvnw.cmd -pl :time-canvas -am test`.
Проверки находятся в `src/test/java/edu/course/games/timecanvas/domain`. Это Jupiter, не отдельный main.
После полной сборки `./mvnw verify` запустите `java -jar app/target/java-games-app-1.0.0.jar 19`.
В IDE запустите `edu.course.app.Launcher` с аргументом `19`. F5 сбрасывает игру, F6 ставит на паузу; код после правки нужно перекомпилировать.
В студенческой выдаче тесты изначально красные из-за незаполненных методов. Это ожидаемо; отключать их нельзя.

## Обязательный design milestone и защита
Добавить группировку нескольких мазков в одну отменяемую транзакцию; сохранить ограничение ёмкости и обрезание redo.
Сохраните существующие контракты через адаптер либо документируйте согласованное изменение и обновите UI с тестами. Полная эталонная версия закрывает базовые контракты; этот запрос студент выполняет самостоятельно.

## AI policy / check questions
Можно использовать AI для объяснения API, поиска гипотез и критики тестов. В `AI_USAGE.md` укажите инструмент, задачу, что принято и как независимо проверено (или «не использовался»). Не засчитывается тест, чей expected просто скопирован из реализации.

1. Объясните `copyPixels` на входе, которого нет в примерах.
2. Какой объект изменяется, кто ещё может держать ссылку на него?
3. Какой тест упадёт при ошибке: Копирование внешнего массива не копирует строки; даже строки длины 0 должны быть отдельными.
4. Выполните небольшой change request без повторной генерации всего класса.
