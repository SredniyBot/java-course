# 19. Холст времени — Независимый снимок рисунка

Undo уже реализован, но ему нужен снимок, который не изменится вместе с холстом. Сделайте глубокую копию.

## Один блок реализации

Замените тело **[CanvasRules.copyPixels](src/main/java/edu/course/games/timecanvas/domain/CanvasRules.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Вернуть независимую копию прямоугольной матрицы int, включая копии всех строк. Новая копия не разделяет строки ни с исходником, ни между собой, даже если в исходнике две строки ссылаются на один массив. При null-строке отклоняется весь снимок; исходник остаётся прежним.

Допустимы пустой массив, пустые строки и строки разной длины; null запрещён. Требуемая сложность: O(числа элементов) времени/памяти.

Примеры: copyPixels([[1],[2,3]]) → равные значения; изменение copyPixels[0][0] не меняет a[0][0].

### Отказы

- `NullPointerException`: если массив или любая его строка равен null.

Если нарушены несколько условий сразу, порядок их проверки не задан. Для проверки конкретного отказа нарушайте одно условие.

## На что обратить внимание

Входные строки могут иметь общие ссылки. При ошибке копирования PixelHistory.commit должен сохранить redo.

## Как выполнить и проверить

1. Откройте метод и его вызов в `TimeCanvasGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :time-canvas -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 19
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

## Готово, когда

- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
