## Приёмка

Базовые публичные тесты обязательны, но не исчерпывают работу. Новая часть оценивается по условиям пункта 3 и доказательствам пункта 4. Зелёные tests без обязательной новой функциональности не означают завершение. Нельзя ослаблять существующий контракт, подгонять expected или удалять проверки ради зелёного статуса.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в FloodRules.

### `void fillFromOrigin(int[][] a,int color)`

- **WHAT / contract:** Перекрасить компоненту клетки [0][0] по четырём сторонам. Использовать очередь из двух int[] размером h w. Помечать клетку новым цветом ДО добавления. Если цвет не меняется, сразу выйти.
- **Constraints:** Непустая прямоугольная матрица width>0; h*w ≤ 10^6; строки разные; любой int цвет. Требуемая сложность: O(h*w) времени/памяти.
- **Examples:** fillFromOrigin([[1,2],[2,1]],9) → [[9,2],[2,1]]; color=1 ничего не меняет.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `fillFromOrigin`, не совпадающий с examples.
- **Typical pitfalls:** Диагональ не связана. Отмечайте посещение до добавления в очередь; тот же цвет — немедленный выход.

### `boolean isUniform(int[][] a)`

- **WHAT / contract:** Все значения равны a[0][0]. Матрица непустая.
- **Constraints:** Непустая прямоугольная матрица width>0. Требуемая сложность: O(h*w).
- **Examples:** isUniform([[2,2],[2,2]]) → true; isUniform([[2,3]]) → false.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `isUniform`, не совпадающий с examples.
- **Typical pitfalls:** Не требуются определённые цвета, только равенство; вход сохраняется.

## Запуск и проверки

Из корня: ./mvnw -DskipTests package, затем java -jar app/target/java-games-app-1.0.0.jar 14.
На Windows используйте .\mvnw.cmd. Это компиляция и запуск демо, не приёмка.

Приёмка: ./mvnw -pl :color-flood -am verify. Незавершённые методы дают IncompleteExerciseException.
При запуске окна та же заглушка даёт намеренно неполноценное поведение. Частично реализованная игра использует ваши готовые методы; ошибки вашего кода не заменяются демо.
F5 сбрасывает сцену; после изменения кода нужна пересборка. В каталоге src/test/java — настоящие Jupiter-тесты.
