# 21. Unicode-сафари — Обрезка по кодовым точкам

Восстановите выделение префикса, не разрывающее суррогатную пару. Объём задаётся в кодовых точках, не в char.

## Один блок реализации

Замените тело **[UnicodeText.prefixByCodePoints](src/main/java/edu/course/games/unicodesafari/domain/UnicodeText.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Вернуть первые n кодовых точек, не разрывая суррогатные пары. Если n больше количества, вернуть всю строку; n>=0. n=0 даёт пустую строку; n больше длины — весь текст. Отрицательное n отклоняется IllegalArgumentException. Как и String.codePointCount, одиночный суррогат считается одной кодовой точкой.

text не null; n ≥ 0. Требуемая сложность: O(text.length).

Примеры: prefixByCodePoints("A😀B",2) → "A😀"; n=0 → ""; n=99 → вся строка.

### Отказы

- `NullPointerException`: если text равен null.
- `IllegalArgumentException`: если n отрицателен.

Если нарушены несколько условий сразу, порядок их проверки не задан. Для проверки конкретного отказа нарушайте одно условие.

## На что обратить внимание

Emoji, комбинируемый знак, n=0, большой n и отрицательный n — разные случаи.

## Как выполнить и проверить

1. Откройте метод и его вызов в `UnicodeSafariGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :unicode-safari -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 21
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

## Готово, когда

- Описанное действие работает в окне, а тесты выбранного модуля проходят без изменения ожидаемых результатов и без включения preview в тестах.
- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
