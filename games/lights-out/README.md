# 15. Ночной город

Погасите все окна. Нажатие меняет окно и четыре соседних.

## Learning outcomes
Локальное изменение и обратимость. Java: boolean[][], инверсия, соседи. После работы студент умеет объяснить контракт и подтвердить его тестом, а не только показать работающий экран.

## Prerequisites
Базовый синтаксис Java, методы и запуск Maven. Предыдущие игры/знания: 08,13. Уровень 2/3, ориентир 60–90 минут без установки JDK.

## Milestones
1. До реализации составьте таблицу граничных случаев и определите владельца массивов.
2. Реализуйте методы с соблюдением контрактов; самостоятельно выберите цикл и вспомогательные методы.
3. Добавьте тест отсутствия лишних изменений и один параметризованный тест.
4. Объясните сложность и продемонстрируйте игру.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в LightRules.

### `void toggleCross(boolean[][] a,int row,int col)`

- **WHAT / contract:** Инвертировать выбранную клетку и соседей по стороне внутри матрицы. Не трогать диагонали.
- **Constraints:** Непустая прямоугольная матрица; row,col внутри; строки разные. Требуемая сложность: O(1).
- **Examples:** toggleCross на пустом по значениям поле 2×2 в (0,0) → [[true,true],[true,false]]. Повторный вызов возвращает исходное поле.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `toggleCross`, не совпадающий с examples.
- **Typical pitfalls:** Диагональ не переключать; центральную клетку переключить ровно один раз.

### `boolean allLightsOff(boolean[][] a)`

- **WHAT / contract:** True, если нет ни одного true.
- **Constraints:** a и строки не null; пустая матрица допустима. Требуемая сложность: O(h*w).
- **Examples:** allLightsOff([[false,false]]) → true; allLightsOff([[false,true]]) → false; allLightsOff([]) → true.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `allLightsOff`, не совпадающий с examples.
- **Typical pitfalls:** Проверка не меняет лампы; один true достаточен для false.

## Tests и запуск
Из корня репозитория: `./mvnw -pl :lights-out -am test`. Windows: `.\mvnw.cmd -pl :lights-out -am test`.
Проверки находятся в `src/test/java/edu/course/games/lightsout/domain`. Это Jupiter, не отдельный main.
После полной сборки `./mvnw verify` запустите `java -jar app/target/java-games-app-1.0.0.jar 15`.
В IDE запустите `edu.course.app.Launcher` с аргументом `15`. F5 сбрасывает игру, F6 ставит на паузу; код после правки нужно перекомпилировать.
В студенческой выдаче тесты изначально красные из-за незаполненных методов. Это ожидаемо; отключать их нельзя.

## Optional extension / запрос на защите

Сохраните существующие контракты через адаптер либо документируйте согласованное изменение и обновите UI с тестами. Полная эталонная версия закрывает базовые контракты; этот запрос студент выполняет самостоятельно.

## AI policy / check questions
Можно использовать AI для объяснения API, поиска гипотез и критики тестов. В `AI_USAGE.md` укажите инструмент, задачу, что принято и как независимо проверено (или «не использовался»). Не засчитывается тест, чей expected просто скопирован из реализации.

1. Объясните `toggleCross` на входе, которого нет в примерах.
2. Какой объект изменяется, кто ещё может держать ссылку на него?
3. Какой тест упадёт при ошибке: Диагональ не переключать; центральную клетку переключить ровно один раз.
4. Выполните небольшой change request без повторной генерации всего класса.
