# 24. Баллистическая почта — Один шаг полёта

Запуск снаряда работает, но он зависает. Реализуйте переход от одного FlightState к следующему по заданной схеме интегрирования.

## Один блок реализации

Замените тело **[TrajectoryPhysics.advance](src/main/java/edu/course/games/ballisticmail/domain/TrajectoryPhysics.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Выполнить один шаг полёта: vyNext = vy + 160·dt, xNext = x + vx·dt, yNext = y + vyNext·dt. Вернуть новое значение FlightState; vx не меняется. Ось y направлена вниз. Даже при dt=0 входное значение не меняется.

dt конечен и лежит в [0,1]. Компоненты FlightState конечны; слишком большой результат отклоняется конструктором FlightState. Требуемая сложность: O(1).

Примеры: FlightState(100,200,10,-20), dt=0.5 → FlightState(105,230,10,60).

### Отказы

- `NullPointerException`: если state равен null.
- `IllegalArgumentException`: если dt не конечен, вне [0,1] или результат содержит бесконечность.

Если нарушены несколько условий сразу, порядок их проверки не задан. Для проверки конкретного отказа нарушайте одно условие.

## На что обратить внимание

Нулевой шаг, падение, бросок вверх, NaN, бесконечность и отрицательное dt.

## Как выполнить и проверить

1. Откройте метод и его вызов в `BallisticMailGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :ballistic-mail -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 24
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.
