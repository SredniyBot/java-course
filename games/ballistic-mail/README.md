# 24. Баллистическая почта

Попадите посылкой в три приёмника.

## Learning outcomes
Value objects и независимая модель физики. Java: Math.sin/cos, радианы, double. После работы студент умеет объяснить контракт и подтвердить его тестом, а не только показать работающий экран.

## Prerequisites
Базовый синтаксис Java, методы и запуск Maven. Предыдущие игры/знания: 02,04. Уровень 3/3, ориентир 90–120 минут без установки JDK.

## Milestones
1. Напишите короткую design note: типы данных, границы ответственности, альтернативы.
2. Зафиксируйте TrajectoryPhysics как адаптер для готового UI; внутренние классы, value objects и API проектируйте сами.
3. Реализуйте контракт и защитите выбор мутабельности; добавьте свои независимые тесты.
4. Обязательная защита: реализуйте запрос на изменение ниже и объясните, какие тесты защищают старое поведение.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в TrajectoryPhysics.

### `Velocity initialVelocity(double angle, double speed)`

- **WHAT / contract:** Вернуть Velocity(x, y): vx=cos(toRadians(angle))*speed, vy=-sin(toRadians(angle))*speed. Ось y экрана направлена вниз.
- **Constraints:** angle конечен abs≤36000 градусов; speed конечен ∈[0,10^6]. Требуемая сложность: O(1).
- **Examples:** initialVelocity(0,10) → Velocity(10,0); initialVelocity(90,10) → Velocity(≈0,-10). Допуск проверок 1e-8.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `initialVelocity`, не совпадающий с examples.
- **Typical pitfalls:** sin/cos принимают радианы; результат — value object, не массив с магическими индексами.

### `boolean isWithinTarget(double x,double target,double halfWidth)`

- **WHAT / contract:** Попадание при |x-target|<=halfWidth.
- **Constraints:** Конечные x,target abs≤10^6; halfWidth ∈[0,10^6]. Требуемая сложность: O(1).
- **Examples:** isWithinTarget(60,100,40) → true; isWithinTarget(140,100,40) → true; isWithinTarget(141,100,40) → false.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `isWithinTarget`, не совпадающий с examples.
- **Typical pitfalls:** Обе границы включены; направление экранной y здесь не участвует.

## Tests и запуск
Из корня репозитория: `./mvnw -pl :ballistic-mail -am test`. Windows: `.\mvnw.cmd -pl :ballistic-mail -am test`.
Проверки находятся в `src/test/java/edu/course/games/ballisticmail/domain`. Это Jupiter, не отдельный main.
После полной сборки `./mvnw verify` запустите `java -jar app/target/java-games-app-1.0.0.jar 24`.
В IDE запустите `edu.course.app.Launcher` с аргументом `24`. F5 сбрасывает игру, F6 ставит на паузу; код после правки нужно перекомпилировать.
В студенческой выдаче тесты изначально красные из-за незаполненных методов. Это ожидаемо; отключать их нельзя.

## Обязательный design milestone и защита
Добавить неизменяемое состояние с позицией и скоростью и функцию update(dt).
Сохраните существующие контракты через адаптер либо документируйте согласованное изменение и обновите UI с тестами. Полная эталонная версия закрывает базовые контракты; этот запрос студент выполняет самостоятельно.

## AI policy / check questions
Можно использовать AI для объяснения API, поиска гипотез и критики тестов. В `AI_USAGE.md` укажите инструмент, задачу, что принято и как независимо проверено (или «не использовался»). Не засчитывается тест, чей expected просто скопирован из реализации.

1. Объясните `initialVelocity` на входе, которого нет в примерах.
2. Какой объект изменяется, кто ещё может держать ссылку на него?
3. Какой тест упадёт при ошибке: sin/cos принимают радианы; результат — value object, не массив с магическими индексами.
4. Выполните небольшой change request без повторной генерации всего класса.
