# 23. Шифр капитана — Шифрование сообщения

Преобразуйте целое сообщение с заданным сдвигом, используя готовую операцию shiftUppercase. Остальные символы сохраняются.

## Один блок реализации

Замените тело **[CaesarCipher.encode](src/main/java/edu/course/games/captaincipher/domain/CaesarCipher.java)**. Это единственный `TODO` игры. Остальные методы и подключение к окну готовы; дополнительных обязательных классов или расширений нет. Приватные помощники допустимы, если они делают этот блок понятнее.

## Поведение

Применить shiftUppercase к каждому char, собрать строку.

text не null; любой offset; меняются только латинские A..Z. Требуемая сложность: O(n).

Примеры: encode("AZ-я",1) → "BA-я"; encode("",7) → "".

## На что обратить внимание

Integer.MIN_VALUE/MAX_VALUE допустимы; проверьте смешанный текст и переносы строк.

## Как выполнить и проверить

1. Откройте метод и его вызов в `CaptainCipherGame`. Для операций, вызванных через готовый адаптер, проследите цепочку до окна.
2. До реализации выпишите результат для обычного случая и указанной границы. Затем замените демозаглушку своим кодом.
3. После лекции 3 объясните результат и состояние данных при успехе и отказе. После лекции 4 закрепите эти случаи Jupiter-тестами; тесты в `src/test/java` уже доступны.
4. Запустите проверку выбранной игры и повторите действие в окне.

```sh
./mvnw -pl :captain-cipher -am verify
./mvnw -DskipTests package
java -jar app/target/java-games-app-1.0.0.jar 23
```

Все команды — из корня проекта. В PowerShell используйте `.\mvnw.cmd`. Пока блок не написан, приёмочные тесты падают, а окно запускается с неполной механикой. После изменения кода нужна пересборка.

## Готово, когда

- Описанное действие работает в окне, а тесты выбранного модуля проходят без изменения ожидаемых результатов и без включения preview в тестах.
- Проверены обычный случай и перечисленные границы; для отказа проверены тип исключения и сохранность данных, если это обещано контрактом.
