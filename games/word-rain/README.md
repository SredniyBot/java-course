# 10. Словопад

Напечатайте 12 падающих слов до их приземления.

## Learning outcomes
Локаль и нормализация на границе. Java: Строки, префиксы, нормализация. После работы студент умеет объяснить контракт и подтвердить его тестом, а не только показать работающий экран.

## Prerequisites
Базовый синтаксис Java, методы и запуск Maven. Предыдущие игры/знания: 09. Уровень 2/3, ориентир 45–60 минут без установки JDK.

## Milestones
1. До реализации составьте таблицу граничных случаев и определите владельца массивов.
2. Реализуйте методы с соблюдением контрактов; самостоятельно выберите цикл и вспомогательные методы.
3. Добавьте тест отсутствия лишних изменений и один параметризованный тест.
4. Объясните сложность и продемонстрируйте игру.

## Контракты заданий
WHAT — требуемый результат; contract — поведение и изменения; constraints — допустимые входы. Предусловия задаёт вызывающий код: вне явно описанного домена поведение не специфицировано, скрытые тесты не требуют придуманной валидации. Null запрещён, кроме явно разрешённых элементов history. Входы не изменять, если контракт прямо не требует мутацию. Нельзя использовать время, случайность, I/O или глобальное изменяемое состояние в WordRules.

### `String normalizeInput(String text)`

- **WHAT / contract:** Убрать пробелы по краям и привести к нижнему регистру с Locale.ROOT.
- **Constraints:** text не null; используются правила String.strip и Locale.ROOT, внутренние пробелы сохраняются. Требуемая сложность: O(n).
- **Examples:** normalizeInput("  JAVA  ") → "java"; normalizeInput("A  B") → "a  b"; normalizeInput("") → "".
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `normalizeInput`, не совпадающий с examples.
- **Typical pitfalls:** trim и strip различаются; регистр не должен зависеть от системной локали.

### `boolean isPrefix(String word,String input)`

- **WHAT / contract:** Вернуть true, если word начинается с input. Пустой input является префиксом.
- **Constraints:** word и input не null; сравнение регистрозависимое, дополнительной нормализации нет. Требуемая сложность: O(input.length).
- **Examples:** isPrefix("java","") → true; isPrefix("java","jav") → true; isPrefix("java","Java") → false.
- **Acceptance criteria:** все приведённые примеры воспроизводятся; границы включены/исключены точно по контракту; результат и допустимые изменения входов проверены отдельными assertions. Добавьте минимум один собственный случай для `isPrefix`, не совпадающий с examples.
- **Typical pitfalls:** Присутствие подстроки не означает префикс; пустая строка — префикс.

## Tests и запуск
Из корня репозитория: `./mvnw -pl :word-rain -am test`. Windows: `.\mvnw.cmd -pl :word-rain -am test`.
Проверки находятся в `src/test/java/edu/course/games/wordrain/domain`. Это Jupiter, не отдельный main.
После полной сборки `./mvnw verify` запустите `java -jar app/target/java-games-app-1.0.0.jar 10`.
В IDE запустите `edu.course.app.Launcher` с аргументом `10`. F5 сбрасывает игру, F6 ставит на паузу; код после правки нужно перекомпилировать.
В студенческой выдаче тесты изначально красные из-за незаполненных методов. Это ожидаемо; отключать их нельзя.

## Optional extension / запрос на защите
Разрешить настройку чувствительности к регистру без изменения isPrefix.
Сохраните существующие контракты через адаптер либо документируйте согласованное изменение и обновите UI с тестами. Полная эталонная версия закрывает базовые контракты; этот запрос студент выполняет самостоятельно.

## AI policy / check questions
Можно использовать AI для объяснения API, поиска гипотез и критики тестов. В `AI_USAGE.md` укажите инструмент, задачу, что принято и как независимо проверено (или «не использовался»). Не засчитывается тест, чей expected просто скопирован из реализации.

1. Объясните `normalizeInput` на входе, которого нет в примерах.
2. Какой объект изменяется, кто ещё может держать ссылку на него?
3. Какой тест упадёт при ошибке: trim и strip различаются; регистр не должен зависеть от системной локали.
4. Выполните небольшой change request без повторной генерации всего класса.
