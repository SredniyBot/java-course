# ADR 005: структура по играм, предметные имена и проверяемые границы

Статус: принято. Дата: 2026-09-21.

Проблема: папки game01 и классы GameLogic/Main сообщают номер и техническую роль, но не предметную область. Общий класс UI одновременно обрабатывал события и рисовал. Одних Maven-модулей и форматирования недостаточно.

Решение: корень организован по назначению (`games`, `platform`, `app`, `testing`, `quality`, `docs`), каждая игра — самостоятельный Maven-модуль с именем предметной области. Номер задания хранится в catalog/roadmap, а не в Java package. Пакет `edu.course.games.<name>.domain` содержит правила и необходимые модели; `ui` — адаптер ввода/анимации и отдельный renderer. Тестовые пакеты зеркалят production.

Классы называются по смыслу: TetrisRules, Utf8Codec, CaesarCipher, PixelHistory. Boolean методы читаются как предикаты, методы изменения сообщают действие. Сохранён небольшой GameSession с состоянием одного окна, но он не передаётся в domain и renderer. Renderer имеет package-private видимость, получает только нужные значения, не владеет игровым состоянием и не сохраняет переданные массивы.

Полноценные модели выделены для трёх конкретных инвариантов: PixelHistory (владение снимками/ветка redo), RobotRunner (состояние исполнения), TileBoard (атомарный ход и допустимые плитки). В остальных небольших играх правила отделены от UI, а координаты и таймер анимации остаются приватным состоянием адаптера. Не создаём 25 пустых service/repository/manager слоёв. Если добавится сохранение или независимый headless engine, соответствующую модель выделяют под новый сценарий.

ArchUnit в app/src/test импортирует классы всех модулей и запрещает обратные зависимости, связи между играми, доступ renderer к контроллеру/GameSession, публичное изменяемое состояние и несколько main. Это проверка реального байткода, а не проверка наличия нужных папок. Граф сборочных модулей дополнительно ограничивает compile dependencies.

Последствия: больше небольших renderer-классов, зато изменение рисунка не затрагивает правила и обработчики. Array-параметры renderer заимствуются только на время вызова на EDT; наружу модели возвращают независимые снимки. Только app содержит Launcher.main. Для запуска одной игры укажите номер в аргументах, а для сборки — предметное имя Maven artifact с `-pl :lunar-tetris`.
