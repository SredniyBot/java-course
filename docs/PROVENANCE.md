# Происхождение

Переработан исходный `java21-interactive-sem2-full.zip`, созданный 14 сентября 2026 года.
SHA-256: `80f87565c20758b5d9aa4d42806bdac370c3898c59e62ea1138e92296cdd0da3`.
Обнаружен в outputs задачи «Создай материалы лекции 2». Сохранены номера, названия,
правила, уровни, управление и графика всех 25 игр. Основой послужили `sem2Answers/game01–25`;
`sem2` использован для сверки состава упражнений. Исходные файлы не изменялись.

Миграция: `common/GamePanel` → GameWindow + GamePanel + DesktopGame + GameSession;
`sem2Answers/gameNN` → `games/<slug>/src/main/java/edu/course/games/<name>/domain` и `ui`;
`LogicChecks.main` → независимые Jupiter tests плюс новые граничные и property tests.
Номера исходных папок сопоставлены именам новых модулей в STRUCTURE.md.
Сохранены 55 учебных операций; их имена уточнены по смыслу. Velocity и Cell заменяют
массивы с магическими индексами в играх 24 и 25. В CaesarCipher исправлено переполнение
при большом offset. PixelHistory продолжает работу при заполнении истории, вытесняя
старейший снимок вместо старого прекращения редактирования.
Подробности архитектуры и владения данными — ARCHITECTURE.md.
